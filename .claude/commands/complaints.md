# complaints

Complaints, compliments and suggestions, with the stage each complaint is at and how many working days it has been open.

Run `node scripts/incidents.mjs complaints [--all]`. Add `--json` when you need every field. Resolve the service, staff member or record by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

For New Zealand complaints, say which Right 10 step is next.
