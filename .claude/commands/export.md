# export

Export every table to one JSON file you own.

Run `node scripts/incidents.mjs export [--out=<file.json>]`. Add `--json` when you need every field. Resolve the service, staff member or record by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
