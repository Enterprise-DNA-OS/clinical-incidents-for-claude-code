# incident

One incident in full: the record, its rating, disclosure, review, every clock, actions, outside notifications, linked feedback and its history.

Run `node scripts/incidents.mjs incident <ref>`. Add `--json` when you need every field. Resolve the service, staff member or record by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Read the whole record before drafting anything about it. Summarise in five lines: what happened, the rating, what is owed and by when, what is done, what is open.
