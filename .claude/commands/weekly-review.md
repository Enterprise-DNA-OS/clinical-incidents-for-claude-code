# weekly-review

The Monday review, written to drafts/: the law, national policy, reviews, complaints, overdue actions and timeframes missed, then the whole attention list.

Run `node scripts/incidents.mjs weekly-review`. Add `--json` when you need every field. Resolve the service, staff member or record by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
