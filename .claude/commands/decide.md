# decide

Record the Right 10(7) decision: justified, not justified, or more time needed (with the number of working days). Over 20 working days, the consumer must be told why.

Run `node scripts/incidents.mjs decide <ref> --decision=justified|not-justified|more-time [--days=<working days>] [--told] --actor="<name>"`. Add `--json` when you need every field. Resolve the service, staff member or record by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
