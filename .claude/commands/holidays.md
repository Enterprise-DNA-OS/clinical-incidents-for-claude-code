# holidays

Public holidays the working-day clock skips. Keep it current each year with /add-holiday.

Run `node scripts/incidents.mjs holidays [--all]`. Add `--json` when you need every field. Resolve the service, staff member or record by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

If next year is missing, say so.
