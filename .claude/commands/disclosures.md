# disclosures

Open disclosure and duty of candour for every incident with moderate harm or worse: which steps are done and which are not.

Run `node scripts/incidents.mjs disclosures`. Add `--json` when you need every field. Resolve the service, staff member or record by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

For a Victorian event the steps are the law. Name the next step for each.
