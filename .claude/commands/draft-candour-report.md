# draft-candour-report

Draft the final written report for a serious event to drafts/: what happened, the apology, how the service responded, what will change, who to contact. Covers the matters the Victorian duty of candour requires.

Run `node scripts/incidents.mjs draft-candour-report <ref>`. Add `--json` when you need every field. Resolve the service, staff member or record by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Draft only. The clinical lead checks every line before it is given to the patient.
