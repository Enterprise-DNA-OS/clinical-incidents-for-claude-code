# sentinel

Sentinel events on the Australian list (version 2), with the category in words.

Run `node scripts/incidents.mjs sentinel`. Add `--json` when you need every field. Resolve the service, staff member or record by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Each one needs the state health department told as its policy requires; check the record shows it.
