# trends

Incidents per month by category for each service over six months, with how many caused harm.

Run `node scripts/incidents.mjs trends [--service=<service>]`. Add `--json` when you need every field. Resolve the service, staff member or record by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Point out any category rising two months running.
