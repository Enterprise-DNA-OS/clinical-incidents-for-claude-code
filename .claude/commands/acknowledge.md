# acknowledge

Record that a complaint was acknowledged in writing.

Run `node scripts/incidents.mjs acknowledge <ref> [--date=<YYYY-MM-DD>] --actor="<name>"`. Add `--json` when you need every field. Resolve the service, staff member or record by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
